# Panel Dashboard

Ce projet est un tableau de bord web moderne pour la gestion de produits, commandes et paramètres, conçu pour une utilisation intuitive et une personnalisation facile.

## Fonctionnalités principales
- **Dashboard** : Vue d'ensemble des indicateurs clés, graphiques de ventes et statistiques.
- **Gestion des produits** : Ajout, modification, recherche et affichage des produits dans un tableau interactif.
- **Gestion des commandes** : Suivi, recherche et visualisation des commandes clients.
- **Paramètres** : Personnalisation des préférences et réglages de l'application.

## Structure du projet
- `Dashboard.html` : Page principale du tableau de bord.
- `order.html` : Gestion des commandes.
- `product.html` : Gestion des produits.
- `setting.html` : Paramètres de l'application.
- `style.css` : Styles globaux et mise en page principale.
- `product.css`, `order.css`, `setting.css` : Styles spécifiques à chaque page.
- `js/` : Scripts JavaScript pour chaque page (ex : `product.js`, `order.js`, etc.).

## Prérequis
- Un navigateur web moderne (Chrome, Firefox, Edge, etc.)
- (Optionnel) [Chart.js](https://www.chartjs.org/) pour les graphiques (déjà inclus via CDN dans les fichiers HTML)

## Utilisation
1. **Ouvrir le projet** :
   - Clonez ou téléchargez ce dépôt sur votre machine.
   - Ouvrez l'un des fichiers HTML (`Dashboard.html`, `order.html`, etc.) dans votre navigateur.
2. **Navigation** :
   - Utilisez la barre latérale pour naviguer entre les différentes sections.
   - Les tableaux sont interactifs : vous pouvez rechercher, ajouter ou modifier des éléments.

## Personnalisation
- Tous les fichiers sont commentés en français pour faciliter la compréhension et la modification.
- Adaptez les styles dans les fichiers CSS selon vos besoins.
- Les scripts JavaScript peuvent être enrichis pour connecter une base de données ou une API.
